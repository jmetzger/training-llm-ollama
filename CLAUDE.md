# training-llm-ollama

Teilnehmer-Material für das 3-Tages-Training "Deploying and Optimizing LLMs with Ollama".

## Konventionen

- Übungen folgen dem Skill `workshop-training` (Format, keine Umlaute in Dateinamen, Code-Blöcke ohne Sprach-Annotation, Aufräumen am Ende).
- Themen-Ordner: `grundlagen/`, `ollama/`, `prompting/`, `rag/`, `langchain/`, `produktion/`, `projekt/`. Die Zuordnung zu den Tagen steht in der README-Agenda.
- Übungen laufen nativ auf der Teilnehmer-VM (Ubuntu, GPU). Kein Docker, kein Kubernetes.
- Jede Übung muss auf einer echten GPU-VM getestet sein, bevor sie in der README verlinkt wird.
- Die README-Agenda ist die Navigationsseite: Jeder Punkt wird erst verlinkt, wenn die zugehörige Datei fertig ist.
